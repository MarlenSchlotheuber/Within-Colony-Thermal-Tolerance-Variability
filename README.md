Here all the data (CBASS ED50, CBASS HOBO, ITS2 data, 16S data) as well as R-script for data analysis and creation of the figures of the manuscript "Exploring Within-Colony Thermal Tolernace Variability in Reef Building Corals" can be found.
1. CBASS ED50 data is the photosynthetic efficiency data of the Coral Bleaching Automated Stress System (CBASS).
2. The HOBO temperature data from the four CBASS tanks from each CBASS experiments.
3. ITS2 SymPortal data is the rDNA amplicon sequencing data after conducting the SymPortal analysis.
4. in Google Drive folder: 16S data is the rDNA amplicon sequencing data that was used for DADA2 analysis. The data can be found here: https://drive.google.com/drive/folders/1abvB3DNnzc-XouBTKKo1wLzBQYiv6rDm?usp=share_link (had issuses uploading the data in Github)
