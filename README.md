Here all the data of the "Exploring Intra-Colonial Variability in Reef Building Corals" Manuscript can be found.
1. CBASS ED50 data is the photosynthetic efficiency data of the Coral Bleaching Automated Stress System (CBASS).
2. ITS2 type profile is the rDNA amplicon sequencing data
3. 16S data is the rDNA amplicon sequencing data that was used for DADA2 analysis. The data can be found here: https://drive.google.com/drive/folders/1abvB3DNnzc-XouBTKKo1wLzBQYiv6rDm?usp=share_link
